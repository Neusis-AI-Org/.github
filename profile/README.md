## 🧠 What We Build

**Neusis** connects every meeting, ticket, PR, and decision across your software development lifecycle through a living knowledge graph called the **Project Brain** — so your team never loses context again.

### Three Products. One Brain.

| Product | Description |
|---|---|
| **Project Brain** | Your organisation's living knowledge graph. Every meeting, ticket, PR, and decision — connected and queryable in real time. |
| **Neusis Code CLI** | Context-aware coding agent. Pulls relevant context directly from the Project Brain — tickets, decisions, architectural rationale — to generate code that actually matches requirements. |
| **Neusis Bot** | Meeting intelligence. Joins Slack Huddles and Teams calls. Auto-extracts decisions, risks, and action items, feeding them directly into the Project Brain. |
| **Neusis Cloud** | Model Gateway & API. Powers the Project Brain's intelligence through multi-model routing across Claude, GPT-4o, and Gemini. |

---

## 🔄 The SDLC Loop

```
Standup → Brain → Developer Context → Code → PR → Linked back to the decision
```

1. **Bot Joins the Standup** — Neusis Bot listens, transcribes, and captures every word in real time.
2. **Brain Captures Context** — Decisions, risks, and action items are automatically extracted and written to the Project Brain.
3. **Developer Opens CLI with Context** — The agent pre-loads the relevant ticket, decision history, and architectural rationale. No hunting, no re-asking.
4. **Code Written. Loop Closed.** — The PR is automatically linked back to the ticket, the meeting, and the original decision.
