## 🧠 What We Build

**Neusis** connects every ticket, doc, repo, and decision across your software development lifecycle through a living knowledge graph called the **Project Brain** — so your team never loses context again.

### One Brain Under Everything.

| Product | Description |
|---|---|
| **Project Brain** | Your organisation's living knowledge graph. Every ticket, doc, repo, and decision — connected and queryable in one place. |
| **Neusis Code CLI** | Context-aware coding agent. In a repo connected to the Project Brain, it starts each session with the project's context docs — PRD, coding style, compliance, and testing rules — and codes against them. |

## 🔄 The SDLC Loop

```
Ticket → Brain → Developer Context → Code → Merge → Back in the Brain
```

1. **Work Lands in Your Tools** — Decisions and requirements live in Jira tickets, Confluence pages, and GitHub issues; Project Brain pulls them in.
2. **Brain Captures Context** — Decisions, requirements, and their links are written to the Project Brain as structured, Git-backed context.
3. **Developer Opens CLI with Context** — In a repo connected to the Project Brain, Neusis Code already has the project's PRD, coding style, compliance, and testing docs. No hunting, no re-asking.
4. **Code Written. Loop Closed.** — Once it merges, a GitHub Code sync that follows the branch brings it into the Project Brain, next to the ticket and the decision behind it.

## ✨ Key Capabilities

- **Always-On Memory** — The Project Brain syncs Jira, Confluence, and GitHub as often as every 15 minutes, so context carries across handoffs.
- **Context Engineering** — The right information, at the right time, in the right form.
- **Full Traceability** — Code, tickets, docs, and decisions sit in one knowledge graph, so you can ask why a piece of work was done.
- **Team-Wide Intelligence** — New hires onboard faster. Senior engineers stay focused.
- **Enterprise Ready** — Project Brain is self-hosted in your own cloud or data centre, one deployment per customer. SSO through Microsoft Entra ID or Google, an audit log, and on AWS, your own KMS key for stored credentials.
